# AnimationRecoder1.0

Small openFrameworks tool for grabbing frames and building stop-motion style animations, with onion skinning. Made during the PIPS:lab years (2013).

## Build

- Addons: `ofxMSAInteractiveObject`
- Generate the project with projectGenerator. Written for OF 0.7.4 (`testApp`), so it will need updating for current OF.

Unfinished, kept for reference.
